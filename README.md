## 🎮 STEAM 2008 (Pre-entrega)



Sitio web inspirado en la estética clásica de Steam, desarrollado como pre-entrega del proyecto final utilizando HTML5, CSS y JavaScript básico.



### 📌 Características

* Estructura semántica con HTML5
* Diseño responsive básico
* Página principal con secciones (inicio, demos, reseñas, contacto)
* Catálogo/tienda con layout tipo Steam clásico
* Sidebar de categorías (estático)
* Slider de juegos con cambio dinámico de imagen, título y precio
* Formulario de contacto (solo visual)
* Estilo visual inspirado en Steam antiguo

### 🚀 Cómo usar

1. Descargar o clonar el repositorio
2. Abrir index.html en el navegador
3. Navegar entre las páginas desde el menú



### 🛠️ Tecnologías

* HTML5
* CSS
* JavaScript (básico para el slider)
